Политика конфиденциальности

Дата последнего обновления: 28 июля 2026 года

Настоящая политика описывает обработку данных в Android-приложении FitTrack (идентификатор пакета ik1ant.fittrack.android). Оператор приложения — Зайнутдинов Ильяс Хасмагомедович. Контактный адрес: ik1ant484@gmail.com.

Кратко: тренировки можно вести полностью локально без аккаунта. Облачная синхронизация включается только после регистрации или входа. Данные Health Connect читаются только с отдельного разрешения, показываются на устройстве и не сохраняются приложением.

1. Какие данные обрабатываются

  • Данные аккаунта: адрес электронной почты, имя или никнейм, технический идентификатор пользователя (UID), статус подтверждения email.
  • Данные тренировок: дни программы, названия упражнений, описания техники, количество повторений и вес.
  • Данные здоровья: суммарно сожжённые калории за текущий день из Health Connect — только после предоставления разрешения.
  • Технические данные: IP-адрес, сведения о сетевых запросах и диагностическая информация, которые могут обрабатываться инфраструктурой Firebase для работы и защиты облачного сервиса.

Пароль передаётся Firebase Authentication по защищённому соединению и не сохраняется в базе тренировок FitTrack.

2. Цели обработки

Данные используются для создания аккаунта, входа и восстановления доступа, отображения профиля, сохранения программы тренировок, синхронизации между устройствами, удаления аккаунта, поддержки работоспособности и безопасности сервиса. Обработка выполняется для предоставления запрошенных пользователем функций и, где это требуется, на основании согласия пользователя.

3. Локальный режим

Без входа в аккаунт программа тренировок хранится только во внутреннем хранилище приложения на устройстве и не отправляется в облачную базу. Системное резервное копирование данных FitTrack средствами Android отключено. Локальные данные удаляются при очистке данных приложения или его удалении.

4. Firebase и передача данных

Для регистрации и входа используется Firebase Authentication, а для синхронизации — Cloud Firestore, сервисы Google. При использовании аккаунта данные профиля и тренировок передаются Google для предоставления этих функций. Обработка Google регулируется Политикой конфиденциальности Google.

FitTrack не продаёт персональные данные, не использует рекламный SDK и не запрашивает рекламный идентификатор. Данные могут быть раскрыты государственным органам только когда этого требует применимое законодательство.

5. Health Connect

FitTrack запрашивает только разрешение на чтение суммарно сожжённых калорий. Значение агрегируется за период от начала текущего дня до момента запроса и отображается в приложении. Оно не сохраняется FitTrack, не включается в облачную синхронизацию и не передаётся Firebase или рекламным системам.

Доступ необязателен. Его можно не предоставлять или отозвать в настройках Health Connect; остальные функции FitTrack продолжат работать.

6. Сроки хранения и удаление

Облачные данные хранятся, пока существует аккаунт и это необходимо для предоставления синхронизации. Пользователь может удалить аккаунт на экране «Аккаунт» в приложении. При этом FitTrack удаляет профиль, облачные тренировки и учётную запись Firebase. Отдельные технические записи могут временно сохраняться поставщиком инфраструктуры для безопасности, предотвращения злоупотреблений или исполнения требований закона.

7. Защита данных

Сетевое взаимодействие выполняется по HTTPS/TLS, незашифрованный HTTP в приложении запрещён. Доступ к облачным данным ограничивается авторизованным пользователем. Ни один способ хранения или передачи не может гарантировать абсолютную безопасность, но применяются разумные технические меры для снижения рисков.

При изменении функций приложения, состава данных или используемых сервисов политика может быть обновлена. Актуальная версия и дата редакции всегда публикуются на этой странице.
