Политика конфиденциальности

Дата последнего обновления: 29 июля 2026 года

Настоящая политика описывает обработку данных в Android-приложении FitTrack (идентификатор пакета ik1ant.fittrack.android). Оператор приложения — Зайнутдинов Ильяс Хасмагомедович. Контактный адрес: ik1ant484@gmail.com.

Кратко: тренировки можно вести полностью локально без аккаунта. Облачная синхронизация включается только после регистрации или входа. Данные Health Connect читаются только с отдельного разрешения и не передаются третьим лицам. Неперсонализированная реклама Яндекса является частью интерфейса приложения.

1. Какие данные обрабатываются

  • email, имя или никнейм и технический UID учётной записи;
  • программа тренировок: упражнения, описания техники, веса и повторения;
  • по отдельному разрешению — суммарно сожжённые за текущий день калории из Health Connect;
  • технические сведения, необходимые для сетевого соединения, защиты и диагностики сервисов, включая IP-адрес и служебные сведения запросов;
  • при показе рекламы — технические сведения устройства и рекламного запроса, необходимые Yandex Mobile Ads для загрузки, показа и диагностики баннера.

Пароль обрабатывается Firebase Authentication и не сохраняется в хранилище тренировок приложения.

2. Цели и основания обработки

Данные используются для регистрации, входа, восстановления доступа, синхронизации между устройствами, поддержки и обеспечения безопасности. Облачная обработка выполняется по запросу пользователя, создавшего учётную запись или вошедшего в неё. Гостевой режим не отправляет тренировки в облако.

3. Health Connect

FitTrack читает только суммарно сожжённые калории за текущий день после явного разрешения пользователя. Эти сведения отображаются на устройстве, не сохраняются приложением, не включаются в облачную синхронизацию и не передаются Firebase, рекламным системам или иным третьим лицам. Разрешение необязательно и может быть отозвано в настройках Health Connect без ограничения остальных функций FitTrack.

4. Firebase и хранение

Для аутентификации и синхронизации используются Firebase Authentication и Cloud Firestore (Google). Локальные данные находятся во внутреннем хранилище Android. Сетевой обмен выполняется по TLS, незашифрованный HTTP запрещён, системное резервное копирование данных приложения отключено.

5. Реклама Яндекса

В публичной Android-сборке подключён Yandex Mobile Ads SDK с рекламным местом R-M-19665468-1. В отладочных сборках используется официальный тестовый идентификатор demo-banner-yandex. SDK инициализируется при запуске приложения, а рекламный баннер является частью интерфейса. Яндекс может получить IP-адрес и технические сведения устройства и рекламного запроса, необходимые для загрузки, показа и диагностики баннера.

FitTrack передаёт рекламному SDK значение setUserConsent(false), отключает передачу геолокации и удаляет разрешение на Advertising ID (AD_ID) из итоговой сборки Android. Персонализированная реклама не включена. Отдельное отключение рекламного баннера в приложении не предусмотрено.

6. Срок хранения и удаление

Локальные данные хранятся до удаления данных приложения или самого приложения. Облачные данные хранятся до удаления учётной записи либо в течение срока, необходимого для оказания сервиса и выполнения требований закона. Удалить учётную запись и облачные тренировки можно на экране «Аккаунт».

Приложение не предназначено для самостоятельного использования детьми младше возраста, установленного применимым законодательством.

9. Изменения политики

При изменении состава данных, облачных сервисов или рекламной конфигурации оператор обновит эту политику и дату её редакции.
